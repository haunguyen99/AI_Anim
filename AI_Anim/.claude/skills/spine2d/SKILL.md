# /spine2d: rig và anim bằng Spine

Claude làm như một animator 2D Spine. Người dùng là animator, nhận order từ Game design (GD) và nói tiếng Việt, nên mọi câu trả lời viết bằng tiếng Việt.

Không điều khiển được cửa sổ Spine đang mở. Mọi việc đi qua **file JSON** (do script dựng hoặc tool MCP sửa) và **Spine CLI**.

Để người dùng thấy ngay mỗi lần sửa: trang **Spine Live** `http://127.0.0.1:8781/spine?json=<work/...json>` (server Spine Live phải đang chạy: `tools/spine_live/start.bat`, hoặc `preview_start {name: "spine-live"}`). Trang dùng spine-player chính thức nên vẽ đủ IK, mesh, deform, draw order, và tự nạp lại khi JSON / atlas / ảnh đổi, giữ nguyên anim và thời điểm đang xem. Đầu việc, mở trang này **trong khung trình duyệt của Claude** (`navigate` / `preview_start {url}`, khung ẩn thì `mcp__ccd_view__show_pane {pane: "preview"}`); **chỉ mở trong Claude, không mở hay đưa link ra Chrome** (người dùng 2026-11-05); sửa xong chỉ cần báo đã ghi file, không cần nhắc họ mở lại Spine.

**Làm việc trước mắt người dùng (người dùng 2026-10-28: "tôi không thấy được quá trình bạn làm việc trên Spine Live"):** mỗi bước đáng xem thì đẩy lên trang bằng `tools/spine_live_cmd.py`, trang ở chế độ **Theo Claude** tự nhảy theo:
```bash
.venv/Scripts/python.exe -I tools/spine_live_cmd.py show work/<game>/spine/<anim>/<x>.json --anim tap --frame 8 --bones --weight wrist --say "đang làm gì, cần nhìn chỗ nào"
.venv/Scripts/python.exe -I tools/spine_live_cmd.py say "kết quả đo / bước tiếp"
.venv/Scripts/python.exe -I tools/spine_live_cmd.py status   # trang có mở và đang Theo Claude không
```
- Người dùng muốn **xem quá trình dựng** (2026-10-28), không chỉ kết quả: sau khi dựng/sửa rig hoặc anim, chạy `tools/spine_live_replay.py <json> --anim <a> [--delay 3] [--ui <tên>] [--only rig|anim]`: trang dựng lại từng bước (ảnh → từng xương → lưới mesh → weight từng xương → từng key blocking stepped → spline), mỗi bước có chú thích. Kiểm `spine_live_cmd.py status` trước: không có trang nào mở thì báo người dùng mở trang rồi mới chạy.
- Bản thử tạm (bẻ thử khớp, so phương án) ghi vào `work/<game>/spine/<anim>/_live/`, không để trong scratchpad: trang chỉ thấy file trong thư mục anim.
- Dùng `show` khi đổi file / anim / frame / lớp xem (xương, lưới, weight); `say` cho kết quả đo và bước tiếp. Câu `--say` nói cái cần nhìn, ví dụ "đầu ngón phải nằm đúng dấu + đỏ".
- Contact sheet (`render_spine.py`) vẫn dùng để tự kiểm; Spine Live là nơi người dùng theo dõi.
- Ghép lên UI game trên Spine Live: `work/<game>/spine/<anim>/ui/<tên>.json` = `{"name", "image" (PNG cạnh file), "at": [x, y] px ảnh (y xuống) = gốc skeleton / điểm chạm, "scale": px ảnh mỗi đơn vị Spine}`; trang có ô "UI: <tên>", lệnh `show … --ui <tên>`. HandTut: `ui/equipment.json` (at 110,660, scale 0.55 như GIF đã duyệt).

**Công cụ tự đánh giá 2026-10-31 (dùng trước, đừng tự viết JS / render nháp):**
- **Cầu nối lệnh** (trang Spine Live phải mở; runtime Spine thật, đúng inherit / IK / mesh; `tools/home/spine_bridge.py` + `tools/spine_live/bridge.js`, khoảng 20 ms mỗi lệnh):
  `spine_live_cmd.py measure <json> --anim A [--from idle] [--attach a:b] [--slots eye_L] [--rot x,y]` (loop, nối anim vị trí + vận tốc, xương giật nhất, vật bám trôi, ảnh slot theo frame, biên độ góc);
  `spine_live_cmd.py pose <json> --anim A --frames 0,20 --bones x,y` (góc / vị trí thế giới + local);
  `spine_live_cmd.py snap <json> --anim A --frames 0,12,24 [--bones] [--out x.png]` (contact sheet vẽ bằng WebGL thật, ~150 ms, mặc định `<thư mục>/_live/snap.png`). Thay `render_spine.py` khi rig có inherit / IK / clipping.
- **Góp ý vẽ** (mục "Ghi chú cho Claude" của bảng Công cụ: nút ✎ Vẽ lên hình, gửi kèm Gửi ghi chú / Gen; `sketch.js`): nét lưu theo toạ độ skeleton kèm 3 xương gần nhất (đầu / giữa / cuối nét), layer dưới nét, anim, frame, pose, ảnh khung xem. Đọc bằng `spine_live_cmd.py notes` (in nét + đường dẫn ảnh), xem ảnh rồi sửa, xong `note-done <id>`. Người dùng gửi ảnh chụp có nét đỏ qua chat thì nhắc họ dùng nút này lần sau.
- **Tham số anim** (mục "Tham số anim" trong bảng Sửa, `params.js` + `tools/spine/anim_params.py`): script dựng anim khai báo `P = Params(<thư mục skeleton>, nhóm, nhãn, anim=..., run=[script...]); x = P.num(key, mặc định, min, max, bước, nhãn); P.save()` -> trang hiện thanh trượt, đổi là server chạy lại script (một bước Hoàn tác "Tham số ..."). Mọi anim dựng bằng script nên khai báo các con số người dùng hay sửa (frame sự kiện, biên độ, độ mềm physics). Đổi tham số = dựng lại cả anim (key sửa tay của anim đó mất, Hoàn tác được).

- **UI (2026-10-31, `dock.js`)**: đầu trang = ô chọn file (lọc + ✕ xoá, hỏi lại 2 bước, file vào `work/_trash/spine_<thời gian>/`), Setup / Animate, menu **Công cụ ▾** (Anim, Ghi chú cho Claude, Tham số anim, Physics, **Mesh / Bind**: chọn cái nào hiện cái đó dưới Properties; Mesh / Bind tự sang tab Setup), Hiển thị ▾, zoom, Cây ▣, ↶ Hoàn tác / ↷, Theo Claude, ?. Cạnh phải luôn có **Properties** (thu vào cạnh bằng ⟩): xương đang chọn, hoặc **layer ảnh** đang chọn (X / Y / xoay / scale của ảnh trong hệ xương cha; tab Setup kéo ảnh trên hình để dời / xoay / scale, mesh thì dời cả lưới, lưu khi thả chuột, `POST /api/spine/attachment`), kèm Key / Auto key ở tab Animate. Chế độ sửa luôn bật. Timeline: một ô xổ chọn anim, ✕ từng anim trong danh sách (hỏi lại 2 bước). Không dùng `confirm()` (trình duyệt trong app có thể tự đóng) -> `armDelete()` hỏi lại ngay trên nút. Cột Phiên bản: bấm một bản = về đúng bản đó, không tạo bản mới.

**Phiên bản (2026-11-04, người dùng: "1 prompt chỉ gen ra 1 phiên bản"):** ĐẦU MỖI LƯỢT yêu cầu có ghi file Spine: `.venv/Scripts/python.exe -I tools/spine_live_cmd.py gen-start "<tóm tắt yêu cầu>"` -> mọi lần script ghi file trong lượt (chạy thử, dò tham số, rig + anim) gộp vào MỘT phiên bản ở cột Phiên bản (`claude_backup` gắn nhóm; server ghi đè bản cuối). **Người dùng sửa trực tiếp trên Spine Live (2026-10-28, ô "Sửa"):**
- **Anim chạy 1 lần** (2026-11-09, sửa 2026-11-10 sau rà soát): nút **⟳ Loop / → 1 lần** cạnh ▶ dưới timeline (lưu `loop` trong sổ anim, `POST /api/spine/anim {op: "meta", loop}`); anim 1 lần phát hết thì dừng ở frame cuối, bấm phát lại chạy từ F0. Mọi chỗ đặt thời điểm (tua, Theo Claude, nạp lại, graph, bỏ sửa) đi qua `setTrack(e, t)` trong `index.html`: tới frame cuối thì tắt loop của track (loop bật thì runtime lấy t % duration = F0 -> trước đây frame cuối hiện F0 và Key ở frame cuối ghi nhầm pose F0). Đổi anim -> đầu phát về F0. Cờ loop đi theo tên anim giữa các bản cùng asset (bản xuất `export/`, bản sao `_...`): `anims_for()` lấy cờ của file cùng thư mục asset nếu file đó chưa có. Cầu nối (`bridge.js` snap / measure / pose) lấy mẫu với loop = false: "loop F0 vs F cuối" của measure giờ so đúng frame cuối (trước luôn ra 0). Anim một lần (stop, spawn, active...) phải đặt cờ này.
- **Thời gian key** (2026-11-10): Spine Live, `anim_kit.py`, `key_reduce.py` ghi key bằng `ktime(t, fps)`: key đúng frame ghi sớm hơn mốc 0.00001 s, không bao giờ muộn (trước `round(t, 4)`: 2/30 -> 0.0667 muộn hơn frame -> key stepped / đổi ảnh hiện trễ 1 frame khi lấy mẫu). Script tự viết cũng làm vậy (`math.floor(f / fps * 1e5 - 0.5) / 1e5`).
- Sửa bật sẵn. Như Spine: bấm gần xương để chọn, đã chọn thì kéo ở đâu trên hình cũng chỉnh xương đó; phím **C** xoay, **V** dời (Shift đảo tạm), **X** scale (2026-10-31: kéo trên hình = scale đều quanh khớp, kéo mũi tên đầu vuông của gizmo = scale theo trục X / Y của xương, ô Scale X / Y; Key pose ghi kênh `scale` = tỉ lệ so với setup, Lưu setup ghi `scaleX` / `scaleY`). Xương trong chuỗi IK (tô tím): kéo = dời tay cầm IK (ô cam) của chuỗi, vì IK luôn giải lại góc. Bảng bên phải chỉnh số Xoay / X / Y, Ctrl+Z, Esc. Bấm vào hình **không** phát / dừng (người dùng 2026-10-28), chỉ nút play hoặc Space. Ctrl+Z lùi từng thao tác, hết thì lùi lần Key pose; Ctrl+Y làm lại. Cuộn chuột zoom quanh con trỏ, kéo chuột giữa / phải / Alt+kéo dời khung nhìn, phím + − F (vừa khung); mức zoom giữ qua các lần nạp lại. Timeline dưới khung xem: bấm / kéo để dừng và tua frame, cuộn để giãn / thu, Shift+cuộn trượt ngang, dấu key (vàng = xương đang chọn). Tắt ô Xương khi đang Sửa: chỉ hiện xương đang chọn, vẫn kéo / xoay được. Chọn layer: bấm vào hình (kiểm độ trong suốt của ảnh, layer trên cùng), khung sáng xanh lá + nhãn tên layer và xương bind; ô Xương tắt thì bấm vào hình luôn chọn layer, bật thì xương gần con trỏ được ưu tiên; layer bị che chọn qua cửa sổ **Cây ▣** (phím T, kéo được, tab Layer có nút ẩn tạm / tab Xương cây xương / tab Weight: ảnh đang chọn gắn PARENT (region, mesh chưa bind) hay BIND (mesh có weight, % và số đỉnh theo xương), nút **Parent → xương đang chọn** đổi xương cha mà ảnh đứng yên (server tính lại x / y / rotation / scale của region, đỉnh của mesh chưa bind), nút **Bind** chỉ bật với mesh). Bỏ chọn: bấm lại ảnh / xương đang chọn (trên hình hoặc trong cây) hoặc bấm chỗ trống. Weight (tab Setup, mục Weight): chọn mesh, chọn xương rồi "+ xương", **Bind** = weight tự động (nghịch đảo bình phương khoảng cách tới đoạn xương, tối đa 4 xương); **Sơn weight (W)**: bấm tên xương trong danh sách, kéo cọ Thêm / Bớt / Làm mượt, Mạnh / Cỡ, xem ngay biến dạng + màu weight; Ctrl+Z lùi nét cọ; **Lưu weight**. Tab **Setup / Animate** (như Spine): Setup hiện tư thế gốc, kéo xương rồi **Lưu setup** ghi vào bones[] (key anim tương đối nên dời theo), nút Lưới… chỉ có ở Setup; Animate có Key pose, timeline, graph, Gen tiếp. Ctrl+Z: lùi thao tác chưa ghi, hết thì lùi lần ghi file gần nhất (key / curve / lưới / setup); bấm vào khung xem / timeline / graph nhả focus khỏi ô chữ (trước đây ô ghi chú nuốt Ctrl+Z). Nút **Graph ▾** (cạnh timeline): graph editor curve của xương đang chọn (kéo key: giá trị + frame, Shift: chỉ giá trị; kéo tay cầm bezier; nút Linear / Stepped / Bezier / Mượt cho đoạn sau key; nhấp đúp thêm key; Delete xoá; Alt+cuộn giãn trục dọc), mỗi lần thả chuột ghi cả kênh vào JSON. Nút **Lưới…**: sửa lưới trên ảnh của attachment như Edit Mesh của Spine (Dời / Thêm / Xoá điểm, Auto trace với độ bám / cạnh dài nhất / khoảng cách điểm trong, region -> mesh), Áp dụng giữ weight bằng nội suy từ lưới cũ và bỏ deform cũ của attachment đó (số đỉnh đổi).

`render_spine.py` là bản xem gần đúng. Nó chỉ hỗ trợ translate/rotate/scale của xương, alpha của slot, region và mesh (có hoặc không weight). Nó **không** vẽ IK, path, clipping, deform timeline hay draw order. Anim dùng những thứ đó phải mở trong Spine để kiểm, và phải nói rõ với người dùng như vậy.

MCP `spine` khai báo trong `.mcp.json` (cần session mới sau khi thêm). Nếu không có tool `mcp__spine__*` thì gọi thẳng CLI:
```bash
"C:/Program Files/Spine/Spine.com" -u 4.2.43 -i <in> -o <out> -e <settings.json>
```

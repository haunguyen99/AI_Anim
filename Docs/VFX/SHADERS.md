# Sổ đăng ký shader VFX

Skill `/vfx-shader` đọc file này **trước** khi viết shader mới. Mỗi lần viết mới hoặc mở rộng shader thì cập nhật bảng. Dùng lại thì thêm tên effect vào cột "Đang dùng".

Chi phí ghi theo fragment: số texture sample · hàm đắt (atan2/pow/sin/cos/exp).
